# Vercel Inspired Design System

Use this skill for developer-centric tools, technical documentation, and high-performance dashboards that prioritize clarity and precision.

## Core Vibe
- Black and white precision
- Geist Sans & Mono fonts
- Informational density
- Minimalist border-based depth

## Design Tokens

### Colors
- **Primary**: #000000 (Black)
- **Secondary**: #ffffff (White)
- **Accent**: #0070f3 (Vercel Blue)
- **Success**: #0070f3 (Status Green)

### Typography
- **Font**: Geist Sans (UI), Geist Mono (Code)
- **Scale**: Small, precise, tight line-height

### Components
- **Buttons**: Sharp corners, solid black/white.
- **Cards**: 1px borders, no shadows.
- **Inputs**: Minimalist, bottom-line or thin border.

## Prompts for Implementation
- "Create a technical dashboard using Vercel's monochrome aesthetic and Geist typography."
- "Redesign this docs page to match Vercel's precision and high-contrast look."
