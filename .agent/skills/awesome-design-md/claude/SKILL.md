# Claude Inspired Design System

Use this skill for AI assistants, editorial content, and applications that need to feel human, thoughtful, and easy on the eyes.

## Core Vibe
- Warm terracotta/orange-red accents
- Editorial serif headings
- Off-white "paper" surfaces
- Thoughtful whitespace

## Design Tokens

### Colors
- **Accent**: #d97757 (Terracotta)
- **Background**: #f9f9f9 (Warm gray/Parchment)
- **Text**: #111111 (Deep charcoal)

### Typography
- **Heading**: Classic Serif (e.g., Spectral)
- **Body**: Clean Sans-serif (e.g., Inter)

### Components
- **Chat Bubbles**: Softly rounded, distinct colors.
- **Inputs**: Large, inviting, minimal distractions.

## Prompts for Implementation
- "Design a chat interface inspired by Claude: warm tones, serif fonts, and an editorial feel."
- "Apply Claude's terracotta accent and paper-like surfaces to this blog layout."
