# Stripe Inspired Design System

Use this skill when the user wants a UI that feels premium, professional, and trustworthy, similar to Stripe's brand identity.

## Core Vibe
- Signature purple gradients
- Weight-300 elegance (Inter font)
- High-depth soft shadows
- Minimalist card-based layouts

## Design Tokens

### Colors
- **Brand**: #635bff (Blurple)
- **Primary**: #0a2540 (Dark Blue)
- **Interactive**: #00d4ff (Light Blue)
- **Surface**: #ffffff (Pure White)
- **Border**: #f0f4f8 (Ultra-light gray)

### Typography
- **Font**: Inter (300/400 weight)
- **Tracking**: Large, airy headings

### Components
- **Buttons**: Rounded (8px), gradient hover, subtle shadows.
- **Cards**: High-depth diffuse shadows, white background.
- **Inputs**: Clean, blue focus glow.

- "Build a payment dashboard with Stripe's aesthetic: purple gradients, soft shadows, and clean cards."
- "Apply Stripe's design tokens to this login page."
