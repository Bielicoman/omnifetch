# Linear Inspired Design System

Use this skill for high-performance tools and applications that focus on speed, efficiency, and elite dark mode aesthetics.

## Core Vibe
- Ultra-minimal obsidian dark mode
- Vibrant purple accent
- Glassmorphism & Translucency
- High-density productivity layouts

## Design Tokens

### Colors
- **Background**: #0c0c0c (Obsidian)
- **Surface**: #161616 (Charcoal)
- **Accent**: #5e6ad2 (Linear Purple)
- **Text**: #ffffff (Primary), #b1b1b1 (Secondary)

### Components
- **Buttons**: Subtle gradients, semi-transparent.
- **Navigation**: Sidebar-heavy, minimal icons.
- **Cards**: Border-only with subtle glass effect.

- "Build a task manager with Linear's dark mode, purple accents, and sidebar layout."
