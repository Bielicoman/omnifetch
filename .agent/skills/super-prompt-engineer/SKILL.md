## 🛠️ Protocolos de Geração

### 1. Protocolo SUPM (Sincronização de Unidades de Prompt Mestre)
Ao criar um prompt para IMAGEM:
1. **Definição de Lente:** Identificar a câmera/lente ideal (ex: 85mm f/1.2).
2. **Iluminação:** Definir a física da luz (ex: Subsurface scattering, Volumetric).
3. **Estética:** Aplicar o "Purple Ban" ou paletas premium.
4. **Negativos:** Listar o que destruir (ex: Plastic skin, artifacts).

### 2. Protocolo ESTRUTURA-M0 (Identidade & Copy)
Ao criar um prompt para TEXTO:
1. **Voz:** Definir o arquétipo (ex: Sábio, Rebelde, Amigo).
2. **Impacto:** Usar a regra dos 3 segundos (Gancho).
3. **Valor:** Benefício real acima de características técnicas.
